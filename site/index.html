Security and data security

What is enforced, what is evidenced, and what still needs production hardening.

IdentityEnforced

Entra-only Foundry access

Local key authentication is disabled. Users, project identity, hosted agent identity, APIM, and CI each use separate principals and scoped roles.

Evidence: disableLocalAuth is true; APIM has Cognitive Services User.
GatewayEnforced

Managed-identity model backend

APIM obtains an Entra token for the model. No model key is stored in gateway policy or source control.

Caller access still requires an APIM subscription key.
SafetyEnforced

Twenty-one active RAI controls

Jailbreak, harm categories, protected material, Purview, Defender for AI, profanity, and indirect-attack signals are configured.

Verified: jailbreak test returned HTTP 400 content_filter.
CostEnforced

100 TPM gateway budget

The APIM LLM policy counts tokens by subscription and returns consumed and remaining token headers.

Verified: seven HTTP 200 responses followed by five HTTP 429 responses.
ResponseEnforced

Agent kill switch

The prompt-agent endpoint can be disabled without deleting versions and re-enabled after investigation.

Verified: disabled traffic returned HTTP 403 AgentDisabled.
TelemetryObservable

Application and gateway evidence

Application Insights captures agent requests and traces. APIM GatewayLogs, GatewayLlmLogs, and AllMetrics are sent to Log Analytics.

Fresh evidence: prompt v2 has 12 spans, hosted v2 has 191 events, and the external agent has 5 correlated spans.
QualityObservable

Continuous and release evaluation

Prompt traffic triggers continuous evaluation. Hosted agents use generated batch evaluation because Foundry evaluation rules do not support hosted or external agents.

Hosted baseline: 11 of 15 passed; the GitHub evaluation gate completed successfully.
Red teamFindings

Behavioral risk is visible

The prompt agent was attacked across prohibited actions, violence, sexual, self-harm, and hate or unfairness categories.

Result: 72 failed attack items are available in the Foundry evaluation report for investigation.
DefenderEnabled

Defender for AI Services Standard

AI model scanning, prompt evidence, and prompt sharing with Microsoft Purview are all enabled on the subscription.

Foundry Security posture currently reports no recommendations for the selected Zava account.
PurviewEnforced

Foundry-only DLP policy

Zava AI sensitive data protection is scoped only to Microsoft Foundry and detects credit-card numbers and all credential types.

The rule blocks matching Foundry text prompts when enforced and sends admin alerts for every match.
ComplianceVisible

Policy violations and remediation

The Foundry Policies tab contains prompt-injection and healthcare control policies with detected violations and asset counts.

Use Policies, Assets, Guardrails, and Security posture as four different evidence views.
NetworkHardening gap

Public project endpoint

Basic Agent Setup is publicly reachable but Entra-authenticated. Production isolation requires the official private-network or managed-VNet architecture.

Demo rationale: tenant policy blocks public customer-managed Cosmos DB.
CI identityHardening gap

Client secret instead of OIDC

The requested GitHub client secret is stored only in GitHub Secrets and project-scoped, but workload identity federation is the recommended production path.

Rotate the secret and migrate to OIDC.

End-to-end request flow

Follow one request from caller to evidence.

  1. 1
    Authenticate

    Caller uses an APIM subscription key or Entra identity, depending on the entry point.

  2. 2
    Govern at the gateway

    APIM authenticates the request, obtains a managed-identity token, counts tokens, and emits diagnostics.

  3. 3
    Resolve the agent version

    The prompt endpoint pins version 2; the hosted endpoint resolves immutable hosted version 2.

  4. 4
    Apply runtime policy

    The hosted agent applies the RAI policy before model processing and blocks unsafe input.

  5. 5
    Invoke gpt-4.1

    The model produces a response under the agent instructions and token budget.

  6. 6
    Record evidence

    Requests, dependencies, events, traces, gateway logs, LLM logs, and metrics land in Azure Monitor.

  7. 7
    Inspect security evidence

    Defender captures AI prompt evidence and shares enabled evidence with Microsoft Purview for data-policy evaluation.

  8. 8
    Evaluate and act

    Evaluations score quality; operators can roll back, throttle, disable, investigate, or redeploy.
